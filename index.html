¿Cómo funciona Bottle Bloom?

Un recorrido completo desde el escaneo hasta la visualización del impacto ecológico.

1
🍶

Presentar botella

El estudiante coloca o fotografía una botella PET.

2
📱

Escaneo demo

La interfaz usa cámara o imagen como referencia visual.

3
🧠

Clasificación

El prototipo simula la decisión de un futuro modelo IA.

4
📲

Pasaporte QR

Cada botella obtiene un identificador ecológico descargable.

5
⛓️

Trazabilidad

Se simula un registro tipo blockchain para explicar el flujo.

6
🌱

Impacto

Clasificación

Tres destinos para cada botella

El sistema orienta la reutilización, reciclaje o disposición correcta.

🟢

Reutilizable

Botella en buen estado, apta para limpieza ecológica y transformación en EcoBottle.

🟡

Reciclaje Industrial

Botella deformada o dañada, enviada a reciclaje especializado.

🔴

Descarte Contaminado

Botella con contaminación alta, destinada a disposición especial.

Demo / Prototipo

Claro para presentar, listo para evolucionar

La web separa lo que funciona hoy de lo que se conectará después con IA real, Firebase y Flow Blockchain.

Funciona hoy

  • Escáner demo con cámara o imagen
  • QR descargable
  • Dashboard con métricas
  • EcoCoins y ranking local

Próxima etapa

  • Modelo IA real
  • Firebase para datos persistentes
  • Flow Blockchain real
  • Integración con estación física
